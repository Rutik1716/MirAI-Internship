🚀 MirAI School of Technology — 2-Month AI Builder Internship

Welcome to my 2-Month Virtual Summer Internship (2026) at MirAI School of Technology, where I explored Artificial Intelligence, Generative AI, Python, and AI-powered application development through hands-on assignments and projects.

Throughout this internship, I developed practical skills in building interactive AI applications, integrating AI APIs, managing conversational memory, generating images using AI, and creating data-driven dashboards.

🎯 Internship Overview

- Organization: MirAI School of Technology
- Program: Virtual Summer Internship 2026
- Track: AI Builder
- Duration: 2 Months
- Role: AI Builder Intern
- Primary Language: Python

🛠️ Technologies & Tools

- Python
- Streamlit
- Google Gemini API
- Pollinations AI
- Pandas
- Git & GitHub
- Generative AI
- Prompt Engineering
- Data Visualization
- Environment Variables and API Key Management

📚 Internship Assignments & Projects

1. The Identity Echo Interface

Built an interactive Streamlit application that accepts user input and displays a personalized AI-style response interface.

Key skills: Streamlit, Python, user input handling, interface design.

2. Upgrading the AI Multiverse

Developed an AI application using the Google Gemini API with multiple AI personalities and adjustable response intensity.

Key skills: Gemini API, prompt engineering, Python, API integration.

3. The Memory Vault

Created a conversational AI application that maintains chat history and supports contextual conversations across multiple messages.

Key skills: Conversational AI, session state, chat history, Gemini.

4. AI Image Studio

Developed an AI image-generation application using Pollinations AI with multiple visual styles, including anime, photorealistic, vintage, sketch, and 3D rendering.

Key skills: AI image generation, API integration, Streamlit.

5. The Multi-Modal Visual Novel

Created a multi-modal AI project combining AI-generated text, conversational context, and generated visual assets to provide an interactive storytelling experience.

Key skills: Generative AI, Gemini, Pollinations AI, stateful interactions.

6. GitHub Profile Development

Designed and organized my GitHub profile to showcase my technical skills, internship assignments, and project portfolio.

Key skills: GitHub, Markdown, documentation, project presentation.

7. Life-OS Wellbeing Dashboard

Developed a Streamlit-based dashboard concept for analyzing lifestyle and screen-time data, visualizing patterns, and generating AI-powered productivity recommendations.

Key skills: Python, Pandas, Streamlit, data visualization, Gemini API.

💡 Key Learnings

- Building interactive applications using Python and Streamlit.
- Integrating Generative AI APIs into practical applications.
- Writing effective prompts for AI responses.
- Maintaining conversational context and chat history.
- Exploring AI-based image generation and multi-modal experiences.
- Analyzing data and presenting insights through dashboards.
- Organizing projects and documenting code using GitHub.
- Managing API credentials securely using environment variables.

📈 Internship Outcomes

This internship provided hands-on experience in applying AI concepts to practical projects, improving my Python development skills, and building a portfolio of AI-powered applications.

It also strengthened my understanding of Generative AI, prompt engineering, API integration, and application development.
